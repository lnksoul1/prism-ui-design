## 一、Pixso 的核心界面模型

Pixso 是典型的**专业设计工具三栏 + 画布**布局（与 Figma / Penpot 同源），其心智模型是"画布为中心，两侧为上下文面板"：

| 区域 | Pixso 的做法 | 作用 |
|---|---|---|
| **顶部工具栏** | 文件标题/面包屑 · 工具（移动/画框/形状/钢笔/文字/评论）· 协作头像 · 分享 · 缩放 · 演示播放 | 全局操作 + 模式切换 |
| **左侧栏** | 图层面板（页面列表 + 图层树，锁定/显隐/层级）+ 组件/资源库 + 页面 | 结构导航 + 复用资产 |
| **画布** | 无限画布 · 点阵网格 · 画板(frame) · 缩放(10%–4000%) · 吸附/标尺 · 实时协作光标 | 所见即所得的编辑主体 |
| **右侧栏** | **属性面板**：X/Y/W/H · 自动布局 · 填充/描边/效果 · 排版 · 导出；原型(交互)标签 · 变量/设计令牌 | 对选中对象的精修 |
| **底部** | 缩放指示 · 快捷键提示 · 版本历史 · 评论 | 辅助信息 |

**2026 年的关键差异能力**（来自 Pixso 官方发布与帮助中心）：
1. **AI Smart Design**：对话生成 UI、画布即出完整界面、所见即所得，且生成的是**组件化、可编辑**的设计稿。
2. **变量系统（Pixso 2.0）**：全局设计变量/令牌。
3. **自动布局 + 约束**：响应式适配多端。
4. **组件库（含变体）+ 设计系统**。
5. **AI 生成组件化 React 代码（Ant Design 规范）**：设计稿一键出可维护代码。
6. **MCP 集成**：把 Pixso 能力暴露给 AI Agent。

> 注：用户提供的具体设计文件 URL 需登录 Pixso 才能访问，无法直接读取其内部画布；本文基于 Pixso 官方文档、帮助中心与发布公告的公开界面/功能描述进行对标。

## 二、Prism 现状 vs Pixso（差距定位）

Prism 的 Dashboard 其实已经大量借鉴了 Figma/Pixso 范式（三栏、图层面板、属性检查器、令牌面板、缩放、组件库、评论、版本、播放模式、实时光标）。对照 Pixso 的差距集中在**精修体验**与**高频操作的流畅度**上：

| Pixso 能力 | Prism 旧状 | 差距 |
|---|---|---|
| 选中即出**浮动操作条**（复制/删除/层级） | 选中后只能去右侧检查器点删除 | 缺高频操作直达 |
| **Ctrl+D 复制组件** | 无复制能力 | 缺（README 曾列为待办） |
| 属性面板**填充/描边/效果**（外观） | 只在组件已带 `bg/color/radius` 属性时才显示 | 外观入口不稳定 |
| **缩放预设**（适应屏幕 / 100%） | 只有 +/− 与百分比 | 缺一键适配 |
| 变量/设计令牌面板 | 已有令牌面板 | 基本对齐 |
| 自动布局 + 约束 | 流式 + 自由定位 + 自动排列 | 部分对齐 |
| 原型/播放模式 | 已有（页面跳转） | 已对齐 |
| AI 生成 UI（画布即出） | 指令引擎 + 模板 + 语义风格 | 已对齐（且不依赖外部 Agent） |

## 三、本轮落地（Pixso 风格精修）

### 1. 选中浮动操作条（`client/index.html` + `client/app.js`）
选中组件时画布顶部中央浮出操作条：**复制 / 上移 / 下移 / 删除**（`renderSelectionToolbar`）。对应 Pixso 选中即现的上下文工具条，减少"去右侧栏点删除"的往返。

### 2. 组件复制（全链路，Ctrl+D）
- `src/state.ts`：`duplicateComponent(id)` —— 深拷贝（新 id、子节点重新编号），插在原组件之后，自由模式自动错位 24px 以便肉眼区分。
- `src/service/design-service.ts`：WS 消息 `duplicate_component` + 共享服务函数。
- `src/routes/components.ts`：`POST /api/component/:id/duplicate`。
- 客户端：浮动条「复制」按钮、检查器「复制」按钮、**Ctrl+D** 快捷键。
- 测试：state / service / server 三层各新增用例。

### 3. 属性面板「外观」区（Pixso 填充/文字/圆角）
检查器新增**始终可见**的「外观」区：填充色（bg）、文字颜色（color）、圆角（radius），带色块预览、支持 `#hex` 与 `8px` 占位提示；输入即回写组件 props（`sendUpdateComponent`）。解决了"组件没有该属性就不显示外观入口"的不稳定问题。

### 4. 缩放预设（适应屏幕 / 100%）
缩放控件新增「适应屏幕」（按画布框/容器比例一键适配）与「100%」两个预设按钮（`setupZoom` 的 `fitCanvas`），对齐 Pixso 缩放区。

### 5. 一致性收尾
- 新增 i18n 键（中/英）并保持双词典键对齐：`appearance/fill/textColor/radius/duplicate/moveUp/moveDown/zoomFit/zoom100` 等。
- 新增 `.selection-toolbar` / `.inspector-actions` / `.zoom-preset` 样式，沿用紫罗兰品牌体系（`--accent` 高亮、`--radius-md` 圆角、毛玻璃浮层）。
- `handleChange` 增加 `duplicateComponent` 分支，复制后画布与图层即时刷新。

## 五、后续建议（未在本轮实施）

| Pixso 能力 | 建议 | 理由 |
|---|---|---|
| 左侧工具竖栏 | 如需更贴近矢量编辑工具，可在 tldraw 画布模式加独立工具条 | 预览模式偏"生成+评审"，竖栏收益有限 |
