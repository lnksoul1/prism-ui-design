为智能体而设计

Prism 是一个跑在 stdio 上的 MCP server。没有内置的 AI 通道，也没有仪表盘——驱动它的智能体就是全部的智能。它只做一件事：把设计变成可以验证、可以交付的产物。

10 个无状态生成工具：配色、字体搭配、字阶、间距、阴影、圆角、对比度、渐变、断点，以及一次调用产出整套设计令牌。

18 个会话工具在服务端维护一份设计状态：初始化、增删改组件、图层排序、对齐分布、多页面、撤销重做，并保存为 .prism.json。

WCAG 审计给出 0–100 分与逐条修复建议；启发式评审从结构、密度、动效与令牌覆盖四个角度补充意见，随后导出成代码。

为什么是 Prism

本地优先

没有内置 AI 通道，也没有 HTTP 服务；驱动它的智能体就是全部的智能。

自包含产物

导出的页面只用内联 CSS，动画由 CSS 实现，不加载任何 CDN 运行时。

状态可持久化

会话状态、撤销历史与项目文件都留在本机，随时保存与恢复。

一次握手，42 个工具

stdio 上的标准 MCP 接口，Claude Desktop、Cursor、Claude Code 或你自己的客户端都能接。

契约可验证

工具清单、组件 schema 与变更路径都有测试守着，文档不会漂移。

MIT 许可

源码开放，随便改，随便用。

把 Prism 接到你的智能体上

npm install && npm run build，然后在你的 MCP 客户端里加一行配置。
