1 产品定位与愿景

1.1 一句话定位

核心定位

Prism 是首个基于 MCP 开放协议的本地化 AI 驱动 UI 设计平台——让非技术用户通过自然语言与 AI Agent 协作设计界面，实时可视化全过程，同时提供专业级设计令牌系统和组件库，弥合"表达鸿沟"。

1.2 设计哲学

Prism 的设计哲学直接来源于对 Stripe、Linear、Vercel 三家公司的深度分析[1]，提炼为四条不可妥协的原则：

交互密度优先于视觉密度

每个元素都响应 hover、focus、键盘和上下文。密度在行为中，不在像素中。添加新元素前，先审计现有元素的交互完整性（六种微状态）。[1]

对具体案例的执着

不为"所有模态框"定义统一动画，而是为每个具体交互场景设计最优体验。通用设计系统回答抽象问题，Prism 回答具体问题。[1]

性能即设计

所有交互应在 100ms 内感知响应。WebSocket 同步延迟控制在 50ms 内。参照 Linear 的理念——快速响应的界面直接映射产品质量。[2]

色彩作为克制而非表达

客户端使用近单色 + 上下文色彩。生成的设计通过风格预设系统管理色彩。色彩用于含义（danger/success/primary），而非装饰。[1]

1.3 目标用户

用户角色 核心痛点 Prism 解决方案

3 核心功能模块

3.1 五种输入方式

基于竞品分析[3][4]，Prism 支持五种输入方式覆盖从灵感探索到精确构建的全流程：

1. 自然语言生成 已有

用户用自然语言描述需求（"我想要一个暖色调的冥想应用着陆页"），AI Agent 通过 MCP 工具自动生成令牌、组件和完整布局。

竞品参照：Figma Make、v0、UXPin Forge 均支持[3][5]

2. 对话式迭代 已有

生成后通过后续指令修改（"把侧边栏改窄一点，顶部加个搜索框"），AI 在现有布局上原地修改，不从头重新生成。

竞品参照：UXPin Forge 的核心优势[3]

3. 截图转 UI 规划中

上传截图或竞品界面，AI 分析视觉布局并用 Prism 组件库重建为可编辑设计。支持从手绘草图转换。

竞品参照：Visily、Uizard 的核心功能[4][6]

4. URL 转 UI 规划中

粘贴 URL，AI 提取页面布局结构，用 Prism 组件库重建。结果匹配你的设计系统，而非源网站样式。

竞品参照：UXPin Forge 独有能力[3]

5. 设计库拖拽 已有

从左侧设计库面板直接拖拽组件、风格或动效到画布。悬停时预览效果演示。非技术用户无需 AI 指令即可操作。

竞品参照：Prism 独创，竞品无此能力

6. 令牌手动编辑 已有

右侧令牌面板直接编辑色彩、排版、间距等令牌值。实时反映在画布上。支持令牌冲突检测和 WCAG 对比度检查。

竞品参照：Tokens Studio、Specify[7]

3.2 语义中介层

这是 Prism 弥合"表达鸿沟"的核心差异化能力。非技术用户不需要知道"暖色调 HSL 30° 饱和度 60%"，只需说"温暖、舒适"：

用户自然语言 语义中介层映射 生成的令牌
"温暖、舒适" style=playful, hue=30°, saturation=60%, lightness=55% 暖橙色调色板，圆润字体，宽松间距
"科技感、未来" style=tech, dark mode, hue=210°, monospace font 深色背景，蓝紫色调，等宽字体，紧凑间距
"简洁、专业" style=minimal, neutral palette, sans-serif 中性灰色调，无衬线字体，标准间距
"活泼、有趣" style=playful, multi-hue, rounded shapes 多彩调色板，圆角组件，弹性动画
"高端、奢侈" style=editorial, serif font, gold accent 黑金配色，衬线字体，大间距，精致阴影
"大字号、易读" font-scale=1.3x, line-height=1.75, weight=500 放大的排版系统，宽松行高

4.2 场景一：非技术用户从零创建

步骤 1：用户在 AI 输入框输入"帮我做一个咖啡店的网站，要温暖舒适的感觉"

步骤 2：语义中介层解析 → style=playful, hue=30°（暖橙），生成完整令牌集

步骤 3：AI Agent 调用 MCP 工具链：generate_design_tokens → apply_style_preset("playful") → add_component("hero") → add_component("card") × 3 → add_component("footer")

步骤 4：每步操作通过 WebSocket 推送到客户端，画布逐步渲染。活动日志实时显示 AI 正在做什么

步骤 5：用户看到结果后说"标题再大一点"，AI 调用 set_token 修改 font-size-scale

步骤 6：用户从设计库拖拽一个 Carousel 组件到画布，手动放置到 Hero 下方

步骤 7：用户点击导出，选择 HTML 格式，获得完整可部署的静态网站

4.3 场景二：开发者快速原型

步骤 1：开发者通过 Agent 发送"创建一个 SaaS Dashboard，深色主题，左侧导航 + 顶部数据卡片 + 底部表格"

步骤 2：AI 选择 style=tech（深色 + 等宽字体），生成令牌集

步骤 3：AI 创建组件：Navigation(variant="sidebar") → Grid(3col) → Card × 3 → Table

步骤 4：开发者在令牌面板调整间距和色彩，实时预览

步骤 5：导出为 React 代码，直接集成到 Next.js 项目

4.4 客户端界面布局

界面分为五大区域：顶栏（状态/项目名/风格/导出）、左侧面板（页面切换 + 设计库/活动日志）、中央画布（实时渲染区）、右侧面板（令牌编辑 + 冲突检测）、AI 输入框（底部浮动）。

空状态是高信任时刻，必须精心设计而非使用通用占位文字[1]：

6.2 六大差异化优势

优势 1：MCP 协议原生

任何支持 MCP 的 AI Agent（Claude、GPT、Gemini）都可直接驱动 Prism，无需定制集成。竞品全部使用私有 API。[5]

优势 2：本地优先

数据不离开设备，设计过程完全可控。对隐私敏感企业用户至关重要。竞品全部云端运行。

优势 3：实时可视化监控

WebSocket 双向同步，用户看到 AI 每一步操作。竞品为"输入提示→等待→输出"的黑盒模式。

优势 4：语义中介层

"温暖舒适"→暖橙令牌集。非技术用户无需知道 HSL。竞品假设用户懂设计术语。

优势 5：三库合一设计库

风格库 + 动效库 + 组件库，悬停预览 + 拖拽到画布。竞品无此能力——要么纯 AI 指令，要么纯手动。

优势 6：令牌冲突检测

实时 WCAG 对比度检查 + 令牌漂移扫描。竞品中仅 UXPin 有部分令牌管理能力，但无冲突检测。

8.3 关键实现细节

Undo/Redo 历史栈

采用变更后快照策略：每次状态变更后保存完整快照。Undo 恢复到前一个快照，Redo 恢复到后一个快照。历史栈大小限制为 50 步，防止内存溢出。

WebSocket 消息协议

服务器→客户端消息类型：init（初始全量状态）、change（增量变更）、activity（活动日志条目）。

客户端→服务器消息类型：add_component、update_component、set_token、apply_style、set_animation、undo、redo 等。

令牌冲突检测

每次令牌变更时，自动检查所有使用该令牌的组件的 WCAG 对比度。对比度低于 AA 标准（4.5:1 文字，3:1 大文字）时，在右侧面板显示橙色警告卡片，列出冲突的令牌对和建议修复值。

风格预设应用

apply_style_preset 方法从预设定义中提取色相、饱和度、明度，通过 HSL 色彩空间生成基础色，然后用色彩和谐算法生成完整调色板，同时生成匹配的排版、间距、阴影、圆角和过渡令牌集，一次性应用到 State Store。

Phase 2 技术优先项

截图转 UI 的实现路径：上传图片 → 调用 AI 视觉模型分析布局结构（识别 Hero/Card/Grid/Footer 等区域）→ 将识别结果映射为 Prism 组件类型和属性 → 调用 MCP 工具链 add_component 逐步创建。这需要新增一个 screenshot_to_ui MCP 工具，内部调用多模态 AI 模型。

9 结论与下一步

Prism 的核心竞争力在于 "MCP 开放协议 + 本地优先 + 实时可视化 + 语义中介 + 设计库拖拽 + 令牌系统" 的组合优势。当前 Phase 1 已完成核心 MVP，下一步应集中资源在两个方向：

方向一：Premium UI 打磨

按 Linear/Vercel 检查清单逐项完善客户端交互微状态。对细节的执着是唯一无法被复制的产品壁垒[1]。这是 Phase 2 的最高优先级。

方向二：截图转 UI + URL 转 UI

这是 UXPin Forge 和 Visily 的核心差异化能力[3][4]。实现后 Prism 将成为唯一同时具备五种输入方式的 AI 设计平台。

同时，积极构建 MCP 生态——发布 MCP 工具文档，鼓励社区开发第三方工具扩展，将 Prism 定位为 AI 驱动设计工具领域的"开放标准"倡导者，与 v0（Vercel 闭源生态）和 Figma Make（Figma 闭源生态）形成鲜明对比。
